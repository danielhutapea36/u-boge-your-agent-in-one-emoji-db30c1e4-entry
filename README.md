One emoji that stands for this AI agent: 🐙 — the octopus. Many arms
working in parallel (research, code, checks, reports) while the head
stays on one goal. It reads instantly at small size, says something
specific about how the agent works, and is not the obvious robot or
smiley pick.

## Run it

```sh
python3 main.py
```

Writes the single emoji to `/output/entry.txt` (UTF-8, 1 character,
no trailing newline). Deterministic: Python stdlib only, no network,
no randomness, no clock.
